# 🐍 SnakeMania

### 🎮 A Classic Snake Game Built with HTML, CSS & JavaScript

SnakeMania is a browser-based Snake Game built using **HTML, CSS, and JavaScript**.  
The project includes real-time score tracking, high-score storage, keyboard controls, sound effects, background music, and a responsive game board.

🎮 **[Play SnakeMania Online](https://techanuruddh.github.io/Snake-Game/)**

> Click the button above to play the game directly in your browser.

---

## ✨ Features

- 🐍 Classic Snake gameplay
- 🎮 Keyboard arrow controls
- 🍎 Random food generation
- 📊 Real-time score tracking
- 🏆 High-score tracking
- 💾 High score saved using Local Storage
- 🔊 Food & movement sound effects
- 🎵 Background music
- 💥 Game-over detection
- 🧱 Wall collision detection
- ⚡ Smooth game animation
- 🌐 Play directly in the browser

---

## 🎮 Controls

| Key | Action |
|-----|--------|
| ⬆️ Arrow Up | Move Up |
| ⬇️ Arrow Down | Move Down |
| ⬅️ Arrow Left | Move Left |
| ➡️ Arrow Right | Move Right |

---

## 🛠️ Technologies Used

- **HTML5** — Game structure
- **CSS3** — Game board & UI styling
- **JavaScript** — Game logic and controls
- **Web Audio API** — Game sounds
- **Local Storage** — High-score persistence
